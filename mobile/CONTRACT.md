# Slowverb Mobile (iPhone) contract
Goal: the phone version of Slowverb: import songs from Files/iCloud Drive (incl. the "Slowverb Phone" folder the Mac app fills), play them with the SAME slowed + reverb "versions" as the Mac player, remember each song's version, keep playing with the screen locked. Wrapped by Capacitor (iOS) later; today everything must run and be testable in a desktop browser at phone size.
Project: ~/Projects/slowverb/mobile (Vite + React + zustand + Capacitor). Read ~/Projects/slowverb/CLAUDE.md first. `@app/*` = ../src/renderer/src/* (shared code), `@shared/*` = ../src/shared/*.
Rules: greyscale blueprint look (tokens in ../src/renderer/src/theme/tokens.css, motion tokens in theme/motion.css: import them), IBM Plex, mono uppercase labels, radius tokens; no em dashes; never `rm` (use ~/.Trash); do NOT git commit; touch ONLY your own files; typecheck with `cd mobile && npx tsc --noEmit` and test with `npx vitest run` (run in mobile/). Files < ~200 lines, tunables in src/config.ts. Other agents' files may not exist yet: code to this contract.

## Shared code you may import (pure, no Electron): `@app/audio/chain` (buildChain), `@app/audio/reverb`, `@app/config/fx` (SPEED, REVERB, DEFAULT_FX), `@app/config/presets` (PRESETS), `@app/features/fx/fx.store` (useFx: fx, preset, applyPreset, set, replace, bypass, toggleBypass, saveUserPreset), `@app/features/fx/Knob`, `@shared/types` (Fx). Do NOT import anything that touches `window.api` or `media://` (engine.ts, library store, player store).

## Agent M1: logic (src/platform/*, src/state/*, src/audio/*, src/config.ts, tests)
- `src/platform/types.ts`: `type Song = { id: string; title: string; artist: string; duration: number; size: number; addedAt: number; fx?: Fx }`; `interface Platform { pickAudioFiles(): Promise<PickedFile[]>; putSong(meta: Omit<Song,'id'>, data: Blob): Promise<Song>; listSongs(): Promise<Song[]>; getSongUrl(id: string): Promise<string> (a URL the <audio> element can play: blob: on web, Capacitor.convertFileSrc on native); deleteSong(id: string): Promise<void>; updateSong(id: string, patch: Partial<Pick<Song,'title'|'artist'|'fx'>>): Promise<void> }`; `PickedFile = { name: string; blob: Blob }`.
- `src/platform/web.ts`: IndexedDB implementation (songs store + blobs store) + `<input type=file multiple accept=audio/*>` picker; `src/platform/native.ts`: Capacitor Filesystem (Documents/songs/<id>.<ext>) + metadata JSON in Preferences-like file, picker via hidden input type=file (WKWebView supports it and opens the Files app incl. iCloud Drive); `src/platform/index.ts` picks by `Capacitor.isNativePlatform()`.
- Tag reading: title/artist/duration from the file (use `music-metadata` browser build if it bundles under Vite; else decode duration via an <audio> element and take the title from the file name).
- `src/state/library.store.ts` (zustand): `{ songs: Song[]; loading: boolean; load(): Promise<void>; importFiles(): Promise<number>; remove(id): Promise<void>; setSongFx(id, fx): Promise<void>; rename(id, title, artist?): Promise<void> }`
- `src/audio/engine.ts`: ONE `<audio>` element + AudioContext + `buildChain` (same chain as desktop: speed via playbackRate with preservesPitch=false, reverb mix/length/darkness). `load(url, fx, autoplay)`, `apply(fx)`, `el`, `ctx`. iOS rules: AudioContext resumed inside a user gesture, `latencyHint: 'playback'`, set `navigator.mediaSession` metadata + action handlers (play, pause, seekto, nexttrack, previoustrack) so lock-screen controls work, keep `playbackState` in sync.
- `src/state/player.store.ts` (zustand): `{ cur: string | null; playing: boolean; pos: number; dur: number; play(id): Promise<void>; toggle(): void; seek(t: number): void; skip(d: number): void; next(dir?: 1 | -1): void; stop(): void }`. Restores a song's remembered fx into `useFx` on play (`replace`), and saves fx changes back to the song (debounced `setSongFx`). Auto-advance to the next song at the end (setting `autoAdvance`, default true). Position persisted per song (resume where you left off) in localStorage.
- `src/state/settings.store.ts`: `{ autoAdvance: boolean; playOnTap: boolean (default true on phone); set(p) }` persisted in localStorage.
- Tests (vitest, fake-indexeddb or in-memory platform): library import/list/delete, fx memory round trip, next/prev wrap, auto-advance rule, mediaSession wiring (mock).

## Agent M2: UI (src/App.tsx, src/ui/*, src/styles/*, src/main.tsx, tools/shot.cjs)
Phone-first, 390x844 reference, safe-area insets (env(safe-area-inset-*)), no hover-only affordances, 44px touch targets, momentum scrolling, no text selection. Screens in ONE app shell with a bottom bar and a mini player:
- LIBRARY: header "SLOWVERB" mono label + IMPORT button (calls library.importFiles); song rows (title, artist, duration, a small version tag like "0.80x · reverb" when the song has a remembered fx); tap = play; swipe left or long-press = delete/rename sheet; empty state explaining how to import from Files (mention iCloud Drive > Slowverb Phone).
- NOW PLAYING: large title/artist, seek bar with times (touch-friendly, thumb 22px), transport (prev, play/pause, next, skip -15/+15 s), version chips (presets from @app/config/presets + user presets) as a horizontally scrollable row, speed + reverb mix/length/darkness sliders (reuse @app/features/fx/Knob styling), A/B ORIGINAL toggle. Entry/exit with a sliding sheet animation (transform only), reduced-motion respected.
- Mini player bar above the bottom bar on Library (title, play/pause, thin progress).
- SETTINGS: auto-advance, play on tap.
Use the stores named in the M1 section exactly (`useLibrary`, `usePlayer`, `useSettings` exported from src/state/*.store.ts). Styling: reuse theme tokens (import '@app/theme/tokens.css' and motion.css), blueprint grid background, hairlines, mono annotations, neon accent for the playing row only.
- `tools/shot.cjs`: Electron script (`cd ~/Projects/slowverb && node_modules/.bin/electron mobile/tools/shot.cjs <url> <out.png> [clickSelector...]`) that opens a 390x844 window on the Vite dev server (http://localhost:5174), waits, optionally clicks selectors, saves a PNG. Used to verify the UI looks right with real data: seed demo songs through the web platform (a dev-only `?demo=1` query seeds 4 songs from small generated tones) and screenshot every screen.
