## Agent E (ops2: editor/ops2.ts, opsRange.ts, opsFade.ts, opsSpeed.ts, validate.ts, ops.ts re-exports, existing ops files, *.test.ts). All pure. Re-export everything from ops.ts.
Existing ops must now honour clip.speed (timeline duration vs source span: trim math maps timeline delta to source delta x speed) and Track.lock; ripple ops take optional `opts?: { tracks?: string[]; syncLock?: boolean }` (tracks = which tracks shift; default = tracks of affected clips, plus all unlocked tracks when p.syncLock !== false).
- gapsOf(p, trackId): { start: number; end: number }[] (end = next clip start; final open gap excluded)
- liftRange(p, a, b, tracks?: string[]): Project            // remove [a,b) leaving a gap (splits at a,b)
- extractRange(p, a, b, tracks?: string[]): Project         // remove [a,b) and shift later left by b-a (all unlocked tracks if syncLock)
- closeGap(p, trackId, t: number): Project                  // remove the gap containing t on that track, shifting later clips (sync-lock aware)
- closeAllGaps(p, trackId?: string): Project                // compact one track (or all) left
- trimToPlayhead(p, t: number, which: 'prevTail' | 'nextHead', ripple: boolean, tracks?: string[]): Project   // Q / W (ripple) and Alt+Q / Alt+W (plain)
- rollEdit(p, leftId: string, rightId: string, t: number): Project    // move the cut between two adjacent clips to t within handles; total length unchanged
- setClipSpeed(p, id: string, speed: number, ripple?: boolean): Project   // clamp 0.25..4; timeline length changes; overwrite or ripple neighbours
- rateStretch(p, id: string, newEnd: number): Project       // choose speed so the clip ends at newEnd
- repeatClips(p, ids: string[], times: number): Project     // loop: n extra copies back to back
- applyCrossfade(p, leftId: string, rightId: string, dur: number): Project   // adjacent same-track clips: use source handles to overlap by dur centred on the cut, set fadeOut/fadeIn = dur; clamps to available handle; returns same p if impossible
- removeCrossfade(p, leftId: string, rightId: string): Project
- insertClips(p, clips: Clip[], at: number, track?: string): Project   // 3-point INSERT: split at `at`, push everything later right (sync-lock), place clips (new ids)
- clipFromSource(src: string, srcDuration: number, srcIn: number, srcOut: number, track: string, start: number): Clip
- patchClips(p, ids: string[], patch: Partial<Pick<Clip, 'gain' | 'fadeIn' | 'fadeOut' | 'name' | 'label' | 'disabled'>>): Project   // fades clamped
- clipsInRange(p, a, b, tracks?: string[]): string[]; clipsForward(p, t, tracks?: string[]): string[]; clipsBackward(p, t, tracks?: string[]): string[]
- nearestEditPoint(p, t, dir: -1 | 1): number | null
- beatGrid(p, fromSec: number, toSec: number): number[]    // uses p.bpm + p.bpmOffset; [] if no bpm
- snapTime gains optional `beats?: boolean` in its options (snap to beatGrid)
validate(p) must now allow same-track overlap ONLY as an explicit crossfade (overlap <= min(earlier.fadeOut, later.fadeIn)) and account for speed. Include seeded random sequence tests over all ops (like wave 1) asserting validate(p) is empty.
