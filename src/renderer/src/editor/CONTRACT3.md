## Agent E2 (ops: editor/opsEnv.ts, opsRangeEdit.ts, existing ops files for env/curve preservation, validate.ts, ops.ts re-exports, tests)
Existing ops (split, trim, move, ripple, speed, paste, duplicate, crossfade, repeat, insert) must PRESERVE fadeInCurve/fadeOutCurve and env: split divides env at the cut (interpolating a point on the cut), trim/rippleTrim clip or shift env points, setClipSpeed rescales env t, move keeps. validate: env sorted, within [0, clipDur], g >= 0.
New pure functions (re-export from ops.ts):
- envAt(c: Clip, tClip: number): number   // interpolated gain (1 if no env)
- setEnvPoint(p, clipId, tClip: number, g: number, index?: number): Project   // add a point (or move point `index`), keeps sorted, clamps
- removeEnvPoint(p, clipId, index: number): Project; clearEnv(p, clipId): Project
- muteRange(p, a: number, b: number, tracks?: string[], fadeSec?: number): Project   // non-destructive silence: set an envelope dip to 0 over [a,b) with short ramps (fadeSec default from config), no splitting needed; merges with existing env
- gainRange(p, a, b, db: number, tracks?, fadeSec?): Project                         // same idea with a gain offset
- fadeRange(p, a, b, kind: 'in' | 'out', tracks?): Project                           // fade to/from silence across the range via env
- setFadeCurve(p, ids: string[], which: 'in' | 'out', curve: FadeCurve): Project
- extendEdit(p, t: number, tracks?): Project            // Resolve E: move the nearest edit point (cut or clip edge) to t, rolling if between two clips else trimming/ripple per sync lock
- trimToPlayheadSel(p, ids: string[], t: number, edge: 'start' | 'end', ripple: boolean): Project   // Shift+[ and Shift+]
- splitAtMany(p, ts: number[]): Project                 // cut at every time (used by detect sections / every N beats)
- cutEveryBeats(p, from: number, to: number, beats: number): Project   // uses p.bpm/bpmOffset beat grid
- trimEnds(p, clipId, startSec: number, endSec: number): Project       // keep only [startSec, endSec] of the clip's source (silence trimming)
Include seeded random-sequence tests that run these through the existing ops and assert validate(p) is empty.
